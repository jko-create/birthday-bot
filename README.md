# 🎂 Telegram Birthday Bot

A completely serverless Telegram bot that automatically reads birthdays from a Google Sheet and sends randomized, engaging birthday greetings to your Telegram group. Powered by Python and GitHub Actions.

## ✨ امکانات (Features)
- **بدون نیاز به سرور (Serverless):** اجرا به صورت کاملاً رایگان و خودکار از طریق GitHub Actions.
- **مدیریت آسان داده‌ها:** خواندن لیست تولدها مستقیماً از یک فایل Google Sheets (خروجی CSV).
- **پشتیبانی از دو تقویم:** پشتیبانی همزمان از تاریخ‌های شمسی (Shamsi) و میلادی (Gregorian).
- **پیام‌های تصادفی (Randomized Messages):** ترکیب بیش از ده پیام تبریک پرانرژی و تکه‌های طنز به زبان انگلیسی برای جلوگیری از تکراری شدن پیام‌ها.
- **لاگ‌گیری دقیق:** سیستم رهگیری و نمایش لاگ در گیت‌هاب اکشنز برای دیباگ آسان‌تر.

## 🚀 راهنمای راه‌اندازی (Setup Guide)

### ۱. تنظیم دیتابیس (Google Sheets)
یک فایل گوگل شیت با دقیقاً این ستون‌ها بسازید:
`name`, `month`, `day`, `cal`, `year`
* **نکته تقویم:** برای تاریخ‌های شمسی در ستون `cal` کلمه `شمسی` را بنویسید. برای تاریخ‌های میلادی می‌توانید آن را خالی بگذارید یا بنویسید `میلادی`.
* **نکته حیاتی خروجی:** دسترسی فایل را روی `Anyone with the link` قرار دهید. سپس در لینک شیر شده، کلمه `edit` و مابعد آن را پاک کرده و `export?format=csv` را جایگزین کنید تا ربات بتواند دیتای خام را بخواند.

### ۲. تنظیم متغیرهای امنیتی (GitHub Secrets)
از آنجایی که این ریپازیتوری عمومی (Public) است، اطلاعات حساس نباید در کد نوشته شوند. به مسیر زیر در گیت‌هاب بروید:
`Settings > Secrets and variables > Actions`
و این ۳ متغیر (Secret) را تعریف کنید:
- `TOKEN` : توکن ربات تلگرام (دریافت شده از BotFather)
- `CHAT_ID` : آیدی سوپرگروه تلگرام شما (معمولاً با `-100` شروع می‌شود)
- `SHEET_URL` : لینک دیتابیس گوگل شیت با فرمت `export?format=csv`

### ۳. زمان‌بندی اجرا (Triggers)
این ربات بر اساس دو رویداد (Event) در فایل `birthday.yml` اجرا می‌شود:
1. **زمان‌بندی خودکار (Schedule):** با استفاده از `cron: '0 5 * * *'` ربات هر روز ساعت ۰۵:۰۰ به وقت UTC (معادل ۸:۳۰ صبح به وقت ایران) بیدار شده و تولدها را چک می‌کند.
2. **اجرای دستی (Workflow Dispatch):** امکان اجرای آنی و دستی کد در هر زمان با فشردن دکمه **Run workflow** در تب Actions گیت‌هاب.

## 🛠 تکنولوژی‌های استفاده شده
- Python 3.12
- `requests` (برای ارتباط با API تلگرام و دانلود شیت)
- `jdatetime` (برای تبدیل تقویم میلادی به شمسی)
- GitHub Actions (به عنوان سرور مجازی)
