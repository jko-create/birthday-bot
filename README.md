# 🎂 Telegram Birthday Reminder Bot

این یک پروژه ساده و کاربردی برای یادآوری تولد دوستان و اعضای خانواده در گروه‌های تلگرامی است. 

### 🚀 نحوه کارکرد:
این ربات به صورت کاملاً خودکار، هر روز (از طریق **GitHub Actions**) یک فایل **Google Sheets** را بررسی می‌کند. اگر تاریخ روز جاری با تاریخ تولد شخصی در لیست تطابق داشته باشد، سن او را محاسبه کرده و یک پیام تبریک به صورت خودکار در گروه تلگرامی مشخص‌شده ارسال می‌کند.

### 🛠 ابزارهای استفاده شده:
- **Python** (برای پردازش تاریخ‌ها و ارسال درخواست‌ها)
- **Google Sheets** (به عنوان دیتابیس ساده برای ذخیره تاریخ تولدها)
- **Telegram Bot API** (برای ارسال پیام تبریک)
- **GitHub Actions** (برای اجرای خودکار و زمان‌بندی‌شده کدها در هر روز)
